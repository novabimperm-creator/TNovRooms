Обновление модуля «Помещения»

Менеджер помещений TNov

Единое окно для округления площадей, квартирографии, офисографии и работы с кладовыми — с обязательными проверками модели и автосверкой с резервными копиями.

Зачем это нужно

Раньше функции по помещениям запускались отдельными кнопками: округлятор, квартирография, офисография, резервные копии и др. Каждая работала сама по себе, и расхождения параметров или площадей можно было заметить только вручную.

Менеджер помещений объединяет основные операции в одном интерфейсе. Перед работой он проверяет модель, подсвечивает ошибки в таблицах и сравнивает округлённые площади с последней резервной копией. Отдельные команды на ленте Revit по-прежнему доступны — их логика расчёта приведена к тем же правилам, что и в менеджере.

Кнопка на ленте: Помещения → Менеджер помещений.

Обязательные проверки при запуске

Пока эти шаги не пройдены, вкладки с функциями заблокированы. Отказ на любом шаге завершает работу плагина.

Шаг 1. Неразмещённые и избыточные помещения

Плагин находит помещения без площади (не размещены на плане) и предлагает удалить их. Если таких помещений нет, шаг пропускается автоматически.

Шаг 2. Параметр «Назначение»

Проверяется системный параметр Назначение у всех помещений. Пустые значения показываются сгруппированными по имени помещения — можно задать «Назначение» сразу для группы. В списке доступны уже используемые в проекте значения и произвольный ввод.

Рекомендуем начинать работу с моделью именно через менеджер: два шага в начале избавляют от типичных «тихих» ошибок, которые потом ломают отчёты и экспорт.

Вкладки менеджера

🧮 Округлятор

  • Список всех помещений модели с фильтром по «Назначению».
  • Проверка: если системная Площадь и N_Площадь.Округленная расходятся на 0,1 м² и более, строка помечается ошибкой.
  • Сверка с последней резервной копией площадей: «соответствует», «было …» или «нет в бэкапе».
  • Кнопка Пересчитать обновляет N_Площадь.Округленная и N_Площадь.ОкруглСКоэффициентом для видимых помещений (с учётом фильтра). После пересчёта можно сохранить новый бэкап.
  • Настройки коэффициентов 0,5 и 0,3 по именам помещений — общие для всех вкладок менеджера.

🏠 Квартирография

  • Только помещения с включённым параметром N_Квартира.
  • Одна строка — одна квартира: сквозной номер, номер на этаже, этаж, состав помещений, площади (общая, с коэффициентом, жилая, балконы), количество комнат, проверка.
  • Автопроверки: устаревшие данные, пустые или дублирующиеся номера, отсутствие жилых комнат, расхождения параметров внутри квартиры.
  • Галочка Пересчитать площади — переокругление перед расчётом квартир (с предупреждением, если в проекте уже есть бэкапы).
  • Поле Номер первой квартиры и кнопка пересчёта сквозных номеров (N_Кв.Номер).
  • Фильтр по этажу и «Только с ошибками». Внизу — Ручной нумератор (заполняет N_Кв.НомерНаЭтаже выбором в модели; после работы менеджер откроется снова на этой вкладке).

🏢 Офисография

  • Помещения с заполненным N_Офис.Номер, сортировка по номеру офиса.
  • Строка — офис: номер, состав помещений, общая, полезная и расчётная площади, проверка.
  • Проверки: устаревшие данные, несовпадение состава, отсутствие параметров, нулевая полезная площадь, офис на нескольких этажах.
  • В блоке настроек — списки исключений имён и коэффициенты (как в прежней команде «Офисография»).

📦 Кладовые

  • Только помещения с именем ровно «Кладовая», не входящие в квартиры и офисы.
  • Колонки: номер, этаж, площадь, округлённая площадь, площадь с коэффициентом, проверка.
  • Порядок строк задаётся перетаскиванием — он определяет будущие номера. Колонка «Новый №» показывает результат до нажатия кнопки.
  • Поле первого номера и кнопка Перенумеровать заполняют системный Номер помещения по всему списку (фильтр по этажу влияет только на отображение).
  • Галочка «Пересчитать площади» — как в квартирографии. Внизу — ручной нумератор помещений (как кнопка «Номера помещений» на ленте).

Резервные копии площадей

При запуске менеджер загружает список бэкапов с сервера. В шапке окна отображается количество копий и имя последней.

  • В Округляторе каждое помещение сравнивается с последним бэкапом по обоим параметрам округлённой площади.
  • После пересчёта площадей (Округлятор, Квартирография, Кладовые) плагин предлагает сохранить новый бэкап — так же, как отдельная команда «Резервные копии».
  • Если бэкапы уже есть, перед переокруглением выводится предупреждение: новые значения могут разойтись с согласованными ранее.
Отдельная кнопка Резервные копии на ленте по-прежнему нужна для просмотра, сравнения и загрузки старых копий. Менеджер ориентирован на работу «вперёд»: пересчитать → проверить → сохранить новый бэкап.

Что изменилось для привычного workflow

Было Стало
Округлятор — отдельное окно без сверки с бэкапом Округлятор в менеджере + колонка сравнения с последним бэкапом и фильтр по «Назначению». Добавили возможность запуска только для помещений с определенным назначением.
Квартирография / Офисография — только пересчёт без сводной проверки Таблица по квартирам/офисам с колонкой «Проверка» и фильтрами
Кладовые — ручной нумератор без общего списка Вкладка «Кладовые»: список, drag-and-drop, перенумерация и проверка площадей
Проверка «Назначение» и неразмещённых — вручную или другими инструментами Обязательные шаги при каждом запуске менеджера

Прежние команды пока не удаляем — они на месте: «Номера помещений», «Округлятор», «Квартирография», «Офисография», «Резервные копии» и др. работают как раньше. Для повседневной подготовки модели к выдаче удобнее пользоваться менеджером.

Краткая памятка

  1. Запустите Менеджер помещений.
  2. Пройдите проверки неразмещённых помещений и «Назначения». Если тут всё ОК — плагин не будет вас тормозить.
  3. На вкладке Округлятор убедитесь, что нет красных строк; при необходимости пересчитайте и сохраните бэкап.
  4. На Квартирографии и Офисографии пересчитайте данные и исправьте строки с ошибками.
  5. На вкладке Кладовые расставьте порядок, перенумеруйте при необходимости.
  6. Перед сдачей этапа ещё раз проверьте, что последний бэкап соответствует актуальным площадям.
